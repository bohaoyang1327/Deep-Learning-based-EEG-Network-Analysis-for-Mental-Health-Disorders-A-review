# Deep-Learning-based EEG Network Analysis for Mental Health Disorders – A Review

This repository contains the materials for the literature review **“Deep-Learning-based EEG Network Analysis for Mental Health Disorders: A Review”**.

The work surveys how EEG-based brain network analysis and modern machine/deep learning methods are used to study and classify a range of mental health disorders, including:

- Autism Spectrum Disorder (ASD)
- Depression
- Epilepsy
- Schizophrenia
- Anxiety and related disorders
- Alzheimer’s disease and other neurodegenerative disorders

We focus on:
- Functional and effective connectivity measures for EEG
- Graph-theoretic analysis of brain networks
- Classical machine learning (e.g., SVM, RF) based on EEG features
- Deep learning models such as CNNs, CNN–LSTMs, GCNs, and hybrid architectures
- Challenges for clinical translation and future research directions


> Author: Bohao Yang, Duke University

> Advisor: Dr. Feng Liu, Stevens Institute of Technology
